Для того чтобы реализовать TCP-CHAT
Необходимо погрузиться в теорию что такое TCP-CHAT и как он может реализоваться
1)В програмной среде существует понятие сокет - это програмнный интерфейс который позволяет обменивать данными между программы (как в глобальной сети интернет, так и в отдельно взятой ОС)
В с++ есть библиотека  <sys/socket.h>, которая позволяет создавать сокеты
сокет выглядит так
int socket(int domain, int type, int protocol);
*Домен - это диапозон адрессов в котором находится сокет и протоколов передачи данных.
Есть два типа:
1)AF_INET - сокет данного домена позволяет взаимодетсвовать в любой сети
2)AF_UNIX - для передачи данных в ОС
*Тип - передачи данных
Существует два типа:
1)UDP - является быстрым протоколом который отправляет данные не заюотясь о проверки качества их доставки
2)TCP - протокол, который позволяет точно передавать данные за счет проверок(правило 3 рукопажатий - SYN, SYN-ACK, ACK)
в этой библиотеки они выступают как
SOCK_STREAM - TCP
SOCK_DGRAM - UDP
Протокол - единый набор правил и стандартов, определяющий, как именно устройства или программы должны устанавливать связь, обмениваться данными и понимать друг друга.

IPPROTO_TCP - сокет TCP

IPPROTO_UDP - сокет UDP

2)Для того чтобы реализовать наш TCP_CHAT, необходимо создать два сокета(сервер, клиент) и связать их
Сокет серера - основная задача ожидать пока отправитель(клиент) отпрравит какое либо сообщение. Поэтому необходимо создать сокет который будет слушать
int server = socket(AF_INET, SOCK_STREAM, 0); // 0 здесь нужен для того чтобы он занимался прослушиванием.
После этого в этой библиотеке нужно будет создать и описать уже имеющиеся в библиотеке функцию, которая будет хранить параметры нашего сервера.

struct sockaddr_in {
    short int          sin_family;  // Семейство адресов
    unsigned short int sin_port;    // Номер порта
    struct in_addr     sin_addr;    // IP-адрес клиента
    unsigned char      sin_zero[8]; // "Дополнение" до размера структуры sockaddr
};
Разберемся что тут по пунктно значит - 
sin_family - семейство адрессов которое мы выбрали, в нашем случае это AF_INET/
sin_port - номер порта к которому мы будем обращаться 
sin_addr - можем поставить какой то точный адресс или же INADDR_ANY (любой ip из нашего диапозона может подключиться).
sin_zero - необходимый дополнение до нашей структуры
3)После создания сокета сервера с описанием его параметров, нам нужно связать его с клиентом
Для это в библиотеке есть функция int bind(int socket, struct sockaddr *addr, int addrlen);

socket - который мы хотим привязать

addr - указатель на структуру sockaddr_in, параметры которой будут переданы в базовую структуру sockaddr.

addrlen - размер структуры sockaddr_in которую вы передаёте для привязки к сокету. Чтобы получить этот размер в байтах, используйте функцию sizeof() в которую передайте ваш sockaddr_in 

3)После того как мы связали наш сокет с адрессом, надо начинать прослушать для этого воспользуемся встроенной функцией
int listen(int socket_server, int backlog);
socket_server - наш сокет сервер который мы создали
backlog - очередь запросов.

4)Принятие запроса клиента
Для того чтобы принять запрос и вернуть новый сокет используется функция accept()

#include <sys/socket.h>

int accept(int socket, void *addr, int *addrlen); 
//возвращает новый сокет клиента
socket - серверный (слушающий) сокет, на который поступил запрос.

addr - указатель на структуру клиента, которая будет содержать данные о его адресе. Если вам не нужны эти данные, можете ставить NULL или nullptr.

addrlen - функция записывает в переменную длину размера структуры addr, тоже можете ставить NULL, если вам это не нужно.

5)Считывание данных - после того как мы наконец установили связь, нам нужно научиться считывать данные
int recv(int new_sock, void* buf, int lenm int flags);

new_sock - новый сокет который получили из accept

buf - указатель на переменную массива char.

len - размер массива buf

flags - комбинация битовых флагов, управляющих режимами чтения. Если аргумент flags равен нулю, то считанные данные удаляются из сокета. Если значение flags есть MSG_PEEK, то данные не удаляются и могут быть считаны последущим вызовом (или вызовами) recv.

Функция возвращает число считанных байтов и в противном случае -1 если не считалось.

5)Закрытие соединения
После того как мы пообщались с сервером, нам нужно закрыть соединение для избежания ошибок при повторном общение.
close(int socket);

6)Подключение сокета к серверу

После того вы создали структуру, содержащую адрес сервера, ваш сокет необходимо подключить (не связать!) к серверу по этому адресу.

Для этого используется функция connect()

Обратите внимание, что при подключении ваш сервер уже должен работать и слушать входящие соединения listen().

#include <sys/types.h>
#include <sys/socket.h>

int connect(int sockfd, struct sockaddr *serv_addr, int addrlen);
Объяснить с

sockfd - сокет клиента, которого будете подключать к серверу.

serv_addr - указатель на вашу структуру sockaddr_in

addrlen - размер (в байтах) вашей структуры. Для получения размера просто используйте функцию sizeof()

7)Отправка данных

После того как ваш сокет подключился к серверу, вы, наконец, можете передавать ему данные.

Для того чтобы отправить данные серверу используется функция send()

#include <sys/types.h>
#include <sys/socket.h>

int send(int sockfd, const void *msg, int len, int flags);
Объяснить с

sockfd - сокет клиента.

msg - указатель на буфер с данными.

len - размер (в байтах) ваших данных.

flags - набор битовых флагов, управляющих работой функции (если флаги не используются, передайте функции 0).

После того как вы отправили данные серверу, не забудьте закрыть все соединения

inet_pton - современный параметр, который отвечает за установку нужного айпи адресса для прогрраммы в наше случае сервере
inet_pton(famalie, ip, &наши параметры);.
