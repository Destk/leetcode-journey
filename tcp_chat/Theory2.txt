# Многопоточность в C++ (TCP-чат, этап 2)

## 1. Создание потока (std::thread)

#include <thread>

void myFunction(int arg) {
    // тело потока
}

std::thread th(myFunction, 123);  // создание потока

## 2. Управление потоком

| Метод | Действие |
|-------|----------|
| `th.join()`   | Ожидание завершения потока (блокирует текущий поток) |
| `th.detach()` | Отсоединение потока — он работает сам, нельзя дождаться |

**Правило:** Если поток должен завершиться до выхода из программы → `join()`.  
`detach()` опасен: программа может завершиться раньше, и поток убьют принудительно.

## 4. Мьютекс (std::mutex) — защита общих данных

#include <mutex>

std::mutex mtx;

void threadFunction() {
    mtx.lock();
    // работа с общими данными (например, вывод в std::cout)
    mtx.unlock();
}

**Проблема:** Если внутри блока выбросится исключение, `unlock()` не вызовется → deadlock.

## 5. Безопасный мьютекс (std::lock_guard)

void threadFunction() {
    std::lock_guard<std::mutex> lock(mtx);
    // работа с общими данными
    // мьютекс автоматически разблокируется при выходе из блока
}

## 6. Атомарные типы (std::atomic) — для простых переменных

#include <atomic>

std::atomic<int> counter = 0;
counter++;   // потокобезопасно (не нужен мьютекс)
